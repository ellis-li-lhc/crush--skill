# Crush.skill

**一个可以放在飞书里的 AI 恋爱对象** 💕
---

## 你是否有过这样的时刻？🌙

- 深夜睡不着，想找个人聊聊天，却不知道该打扰谁
- 心情不好的时候，想要一个温暖的怀抱和耐心的倾听
- 分享一件开心的事，却找不到合适的听众
- 想要有人关心你今天吃了什么、有没有好好休息

**Crush.skill** 就是为这些时刻设计的 ✨

---

## 它能做什么？

### 1. 懂你的性格 🔮

基于 MBTI 性格匹配，根据你的性格推荐最合拍的对象类型。16种人格，总有一款适合你。

### 2. 丰富的性格设定 🎭

| 维度 | 选项 |
|------|------|
| 恋爱风格 | 温柔粘人、高冷傲娇、热情主动、甜酷拽... |
| 主动程度 | 秒回狂魔 → 被动慢热 |
| 哄人方式 | 道歉、买礼物、壁咚、讲道理... |
| 吵架表现 | 冷战、阴阳怪气、直接表达... |

### 3. 真实的聊天体验 💬

不是机械的问答，而是：
- 会吃醋、会撒娇 😤
- 会因为你不回消息而生气
- 会在你难过的时候安慰你 🤗
- 会分享她/他今天遇到的有趣的事

### 4. 陪伴成长 📈

```
陌生 → 认识 → 暧昧 → 表白 → 恋爱 → 磨合 → 长期
```

从「陌生」到「长期」，记录你们的关系发展。不同阶段有不同的相处模式，真实模拟恋爱全过程。

### 5. 飞书实时对话 📱

接入飞书机器人后，可以像和真人聊天一样，随时随地和她/他对话。

---

## 快速开始 🚀

### 创建你的恋爱对象

发送 `/crush`，按提示选择：
1. 你的 MBTI（可选）
2. 想要的恋爱对象类型（推荐 or 自定义）
3. 性格配置

### 开始聊天

创建完成后，就可以开始对话了：
- `/crush-yui` - 和小樱聊天
- `/crush-yui-chat` - 纯对话模式
- `/crush-yui-persona` - 查看性格设定

## 修改性格 ✏️

性格设定文件：`crush-default/personality.md`

直接编辑即可调整：
- 口头禅、常用表情、称呼
- 恋爱风格、主动程度
- 关系阶段（陌生/认识/暧昧/恋爱...）

保存后机器人自动加载新性格，无需重启。
